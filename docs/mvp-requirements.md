# 图文社区第一版需求

状态：规划稿，作为后续工程搭建和功能开发的基线。本文中的数值与登录方式为建议默认值，尚未由用户逐项确认；实现前可调整，不代表现有功能已完成。

## 目标与范围

先交付 uni-app H5 图文社区和独立运营后台，所有客户端共用 NestJS 接口。后续适配微信小程序、iOS 和 Android。技术基础为 Vue 3、TypeScript、PostgreSQL、Prisma 和 pnpm workspace。

第一版支持图文发布、浏览、搜索、互动、关注及审核。视频、私信、商城、直播、个性化推荐、评论回复、富文本编辑、社交登录、密码找回和通知中心暂缓。

## 角色与访问规则

游客可浏览公开内容、搜索和查看公开个人主页；点赞、收藏、评论、关注、发布及举报需要登录。普通用户只管理自己的资料、笔记和评论。管理员通过独立后台处理内容和用户，不开放管理员自助注册。

所有权限在服务端验证。客户端隐藏按钮不能代替权限校验。公开接口不得泄露邮箱、密码摘要、收藏列表或内部审核信息。

## 功能与验收

### R01 账号与登录

建议内部测试版采用邮箱加密码注册、登录，不接入邮件验证或短信服务；邮箱仅为账号标识，不视为已验证邮箱。密码不明文保存、不进入日志。注册接口需要限流。公开注册前必须重新评估账号验证与找回流程。

验收：相同邮箱不能重复注册；错误凭据不能登录；登录过期后可重新登录；退出后原会话不可继续访问受保护接口；匿名请求不能发布。建议密码 8–64 位，邮箱去除首尾空格并统一大小写后判重。

### R02 个人资料与主页

用户可以修改头像、昵称、简介。公开主页展示公开资料、关注和粉丝数量及公开笔记；收藏列表仅本人可见。建议昵称 2–20 个字符，简介最多 200 个字符，初始昵称由系统生成。

验收：修改后重新加载仍保留；其他用户不能修改；公开响应不包含邮箱或收藏列表；待审核、隐藏及删除内容不出现在公开主页。

### R03 图片上传

建议每篇笔记 1–9 张图片，单张最多 10 MiB，支持 JPEG、PNG、WebP；第一版不接受动图和 SVG。第一张图作为封面。图片存入对象存储，数据库保存对象标识和尺寸等信息。

验收：上传前后都校验大小和真实格式；用户可以调整顺序和移除图片；失败可重试；不能引用他人的未绑定上传对象。待审核图片不提供永久公开访问地址，读取权限跟随笔记状态。孤立上传按约定保留期清理，清理不得删除仍被笔记引用的对象。

### R04 图文笔记管理

建议标题必填 1–40 个字符，正文必填且最多 2000 个字符，标签可选、最多 5 个、每个最多 20 个字符。文字长度按 Unicode 码点计算，必填字段去除首尾空白后校验。正文按纯文本展示。发布前可预览，离开未提交编辑页提示确认；第一版不做服务端草稿。

验收：发布、编辑、删除仅限作者；客户端重复提交不产生重复笔记；任一图片上传失败时不可提交不完整笔记；发布后进入待审核状态。编辑公开笔记后重新待审核，并从公共列表撤下。删除后公共详情不可访问，公共列表不再展示，重复删除结果一致。

### R05 发现页与详情

发现页按发布时间倒序展示公开笔记，使用创建时间和唯一 ID 作为稳定游标。详情包含图片、正文、作者、标签、互动数量与评论入口。提供加载、空白、错误和重试状态，图片保留宽高比例并懒加载。

验收：同一浏览过程中加载下一页不重复展示已有笔记；游客能打开公开详情；非公开笔记对无权用户显示统一的不可访问结果；作者从自己的内容列表可查看审核状态和原因，内部审核记录不公开。

### R06 搜索

按标题和正文进行基础关键词匹配，仅搜索公开笔记；结果按发布时间与唯一 ID 排序并分页。第一版不包含拼音、纠错、联想或个性化排序，先使用数据库实现基础匹配。

验收：首尾空格被处理；空关键词不发起搜索；建议关键词最多 50 个字符；中文关键词可匹配；无结果有明确提示；隐藏和删除后不再命中。

### R07 点赞与收藏

登录用户可点赞、取消点赞、收藏和取消收藏；自己的收藏列表提供分页，失去公开状态的笔记不返回正文和图片。

验收：同一用户对同一笔记最多一条点赞和一条收藏；重复或并发操作不会重复计数或产生负数；刷新后状态保持；其他用户无法读取该收藏列表。

### R08 评论

登录用户可对公开笔记发表一级纯文本评论，建议 1–500 个字符，去除首尾空白后校验。评论默认按时间正序分页；用户可删除自己的评论，管理员可隐藏违规评论。评论回复暂缓。

验收：空白评论不可提交；他人不能删除评论；隐藏、删除评论不在公共列表展示；笔记不公开时不能新建评论。评论文本必须作为文本渲染，不能执行脚本。

### R09 关注与关注页

登录用户可以关注、取消关注并查看自己的关注流；公开主页可查看公开的关注与粉丝列表。关注流仅包含已关注作者的公开笔记，排序及分页规则与发现页一致。

验收：不能关注自己；重复或并发关注不产生重复关系；取消后关注流不再返回该作者内容；未关注任何作者时显示引导。

### R10 举报与审核

登录用户可举报笔记、评论或用户，选择原因并可补充说明，建议说明最多 500 个字符。相同用户针对相同对象同一时间仅保留一条待处理举报。管理员查看举报并记录处理结果。

笔记采用人工先审后发：待审核 → 公开或驳回；作者修改驳回内容后可重新送审；公开内容可被管理员隐藏；隐藏内容仅管理员复核可恢复公开，作者修改后也可重新送审。任意未删除状态可由作者删除，删除为终态。驳回或隐藏必须填写原因。评论先发后审，支持举报及管理员隐藏。

验收：待审核内容仅作者及管理员可见；批准后进入公共列表；隐藏立即影响详情、搜索和列表及媒体读取权限；举报处理人、时间、结果可追溯。评论恢复前检查父笔记仍公开。

### R11 管理后台与禁用

提供管理员登录、用户查询、笔记审核、评论管理、举报处理和操作记录。禁用用户立即使其会话失效，禁止再次登录及写操作；既有内容独立处理，不因禁用自动删除。管理员权限只能通过受控的初始化或管理流程赋予。

验收：普通用户无法调用后台接口；禁用用户的现有会话不能继续写入；恢复用户后可重新登录；审核、禁用及恢复操作记录管理员、对象、时间和原因，日志不记录密码或令牌。

### R12 运行与交付

环境配置示例可提交，实际凭据不得提交。建立数据库迁移、接口校验、错误日志、备份和恢复说明。对注册、登录、上传、评论和举报设置可配置限流；具体额度在测试版联调时确定。客户端不能将服务端异常堆栈直接展示给用户。

验收：新环境按说明可启动；全部自动化测试、类型检查和构建通过；测试环境可完成双账号闭环；备份恢复验证通过。真实用户开放前落实审核人、媒体权限、账号验证、域名及各平台发布要求。

## 建议默认值与待确认项

- 登录：先以邮箱密码完成内部测试，公开开放前确定验证与找回方案。
- 审核：个人开发阶段由管理员人工先审后发，后续可接内容审核服务。
- 媒体：云厂商、地域、访问鉴权方式、孤立上传保留期和存储预算在上传模块开工前确定。
- 内容边界：以上图片数量和文字长度作为可配置默认值，客户端与后端共享约束。
- 视觉：先完成移动 H5，自适应桌面宽度；产品名称、主题色和详细视觉稿另行确定。
- 适配：先完成 H5，后续平台复用业务逻辑并分别验证登录、上传、权限和发布流程。

## 开发顺序

需求与页面流程 → 工程基础 → 账号资料 → 上传及笔记 → 浏览搜索 → 互动关注 → 审核后台 → 测试版部署 → 小程序 → App。

后台审核在图文发布联调阶段先提供最小可用能力，避免发布流程因待审核无法验证；随后补齐后台其余功能。

页面入口、角色流程和端到端验收见 [页面与验收流程](mvp-flows.md)。每个独立功能配套测试，验证后中文提交；阶段验收运行全部已有检查。
